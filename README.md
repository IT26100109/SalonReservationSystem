# 🌸 Velvet & Rose Salon - Beauty Salon Reservation System

A sleek, modern full-stack web application for **Velvet & Rose Salon**, designed to manage salon appointments, treatments, boutique retail offerings, customer loyalty tiers, and user feedback.

## ✨ Features

- **User Authentication & Authorization**: Secure login and registration.
- **Customer Loyalty System**: Tracks member activity, total spend, and unlocks loyalty tiers.
- **Appointment Reservation**: Seamless service booking with dynamic cost calculation.
-  **Staff Management**: View the Staff members working for the company and the abilty to ediit their stats.
- **Service & Product Management**: Categorized view of salon services and boutique products.
- **Review & Rating System**: Built-in system for clients to post reviews and star ratings.
- **Responsive & Modern UI**: Aesthetic dark-mode glassmorphism interface built with Spring Boot and Thymeleaf.

---

## 🛠️ Tech Stack

- **Backend Framework**: Spring Boot (Java)
- **Frontend / Templating**: Thymeleaf, HTML5, CSS3, JS
- **Database**: MySQL
- **Build Tool**: Maven
